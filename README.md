Entry for the make.fun bounty [Make the best card game](https://make.fun/bounty/best-card-game-20261122-1826).

**Lantern Duel** — an original turn-based card duel. You and the Keeper each hold 20 light; spend ember to play strikes, mends, wards and kindles across four elements (Flame ▲, Tide ●, Leaf ◆, Spark ★) with a counter wheel. Snuff the Keeper's lantern to win.

`game/` is plain static files (canvas, ES modules, no network). `main.ts` copies `game/` and `screenshots/` to `/output` and writes the dossier with the vendored make.fun library. Play locally with `node serve.ts`.
